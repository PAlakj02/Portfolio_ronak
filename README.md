# Raunak Garhyan Portfolio

Vite + React portfolio site.

## Run locally
```bash
npm install
npm run dev      # http://localhost:8080
npm run build    # outputs to dist/
```

## Structure
- `src/pages/DesignProjects.jsx`: home page reel (auto carousel, explore cursor, bento modal)
- `src/pages/About.jsx`: about page and logo strip
- `src/pages/Hci.jsx`: HCI / Other Projects
- `src/works.js`: design project titles, descriptions and images
- `src/pages.js`: nav, email and CV link
- `public/`: images, logos, video and CV PDF

## Deploy
Works on Vercel out of the box (`vercel.json` handles page routes).
